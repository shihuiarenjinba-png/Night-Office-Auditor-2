# 深夜監査室 有料拡張版 — 24案件「証拠→矛盾→結論」完全照合表

**用途:** 制作・QA用のネタバレ資料。ゲーム内では報告前に真相を直接表示しない。すべて架空の会社・人物・記録に基づくフィクション。

## 完成条件 / 判定の禁止事項

1. **事件の違和感 ≠ 犯罪:** 時刻のずれ、空欄、共有IDだけで人物を犯人と認定しない。
2. **一次資料と時系列:** 伝票・決済・操作ログ・承認票を固有IDで突き合わせる。単独の「怪しい」情報は決定打にしない。
3. **代替説明を検証:** 正当な取消、時差変換、バッチ処理、旧コード移行、入力ミスの可能性を先に検討する。
4. **共通IDと個人を区別:** 共有ログイン `svc-night`、端末 `T-7`、処理経路 `EX-213` は「接点」であって、利用した自然人の証明ではない。
5. **人物特定の条件:** 個人認証記録、端末セッション、物理記録、本人の供述などが同じ時刻・行為に収束すること。ログインがあっただけでは操作行為を断定しない。
6. **認定と未確認を分ける:** 報告後に公開される資料は「事後照合」と明記し、報告前に取得した資料と混ぜない。
7. **有料版の作業範囲:** 専用Work branchで制作する。低価格版のゲーム本体・セーブ・Store Identityは変更しない。

## 大筋の解答設計

- 第1章（N01〜N06）：正当な欠番と実際の支払先改変が混在する。**怪しさと不正は同義ではない**ことを学ぶ。
- 第2章（N07〜N12）：夜間バッチによる正常な02:13と、承認外請求・寄付差額を分離する。
- 第3章（N13〜N18）：T-7 / EX-213の共通経路が現れるが、この段階では操作した自然人はまだ確定しない。
- 第4章（N19〜N24）：管理番号の見かけの一致と真の不一致を区別。最終案件で初めて**本人認証＋端末＋現場記録＋供述**を突き合わせ、4件の無承認改訂の操作主体を認定する。
