## 深夜監査室に採用する原則

### 1. 遊び方は明確、真相は伏せる
- 事件開始時に「既知の事実」「解明すべき疑問」「残り調査枠」を明示する。
- 資料カードの表には**文書名・種類・文書ID**を示し、何を開けるべきかを合理的に選べるようにする。
- 裏には**観測された事実だけ**（氏名、時刻、金額、原票番号、録画範囲、ログの制約）を記す。**「つまり」「不正だった」「正解は」などの推理結果を載せない**。
- 資料2点以上を「どの疑問の根拠か」に結び、回答候補を選択して仮説を立てる。**正誤の自動判定・真相開示は提出後**。
- 提出時には「当たったか」だけでなく、選んだ**資料が実際にその結論を支持するか**を評価する。

### 2. 証拠枚数制限は戦略にし、理不尽な運ゲーにはしない
- 事件ごとに `cardCount` と `revealLimit` を決め、開封前に表示する。
- 「全8枚のうち6枚開けるが、真相解明に必須なものが6枚すべて」という設計を原則禁止する。1枚の選び損ないで全解決不能になる。
- 最小解明手段は開封枠より余裕を持たせる。**主証拠4枚程度＋補強や対立証拠・人物事情を取捨選択**するのがCASE04再設計の第一候補。
- 同じ結論を別の資料で立証できる複数の正当な経路を用意する。ただし「一番それらしい資料なら何でも正解」にはせず、証拠の論理的妥当性を記載する。
- 証拠不足の場合は**追加調査**として進行可能とし、あとから別経路で検証する機会を設ける。
- 再試行に必要な情報を隠したまま罰を与えない。過去に開けた資料は常時再閲覧でき、低コストの**段階的ヒント**は調査手順から教える（直接正解カード名を教えない）。

### 3. 人間ドラマと推理が互いに影響する
- 関係者はそれぞれ自分の目的を持つ。登場人物の反応が台詞の言い換えだけにならない。
- プレイヤーが誰を信頼・追及したかによって、**資料を受け取る順番、証言、利用可能な調査経路、次話での協力**が変わる。
- それでも真相を選択に合わせて変えない。誰が何をしたかは証拠に基づき固定し、変えるのは**どこまで証明できたか／どんな犠牲を払ったか**。
- 正規バッチ処理・共有ID・個人ログイン・本人による操作・不正取得を、証拠のレベル別に分ける。人物の断罪には独立した裏付けが必要。

### 4. 単発24件でなく「事件横断の推理手帳」
- 全案件の文書・人物・会社・端末・時刻を、固定IDと出典付きで記録する。
- **事件Aで見た記録が事件Bで新しい疑問を生む**。後から過去の証拠を見直し、横断的に関連付けられる。
- 序盤は「一つの経理記録を調べる」、中盤は「人物間の対立と共通する操作経路」、終盤は「何が誰によって改訂されたかを横断的に立証する」と階層を進める。
- 伏線は必ず、初登場時点で**再閲覧できる文書ID・具体的事実**を持つ。後付けで「実は以前出ていた」扱いにしない。
- 最終報告は「誰が／いつ／何を／どの証拠で／どこまで立証できるか」。報告した範囲と人的信頼関係で結末に差をつける。未確定の受益者・動機を勝手に断定しない。

## 初回の完成品質検証: 3事件の縦切り（予定、未実装）
- **CASE01 消えた伝票:** 正当な二重起票取消を見抜く。紙だけを見ると誤解するが、取消IDと時系列・承認で疑いが解ける。
- **CASE04 白紙の承認欄:** 電子承認ID／発注時刻／代理権限を独立に判断。人物との接し方で資料の取得経路が変わる。現在の8枚・6枚の「すべて必須」方式を修正し、最低4枚で合理的な判断ができる別経路を試作する。
- **CASE05 変わった振込先:** 本当に重大な不一致がある事件。共有端末T-7を発見しても利用者個人の罪はまだ立証できない。前の事件の人物・監査室の信用度により協力者と調査の難度が変わる。

3事件をまたぐ**小さな伏線**を用意し、プレイヤーが「別事件なのに同じ要素があった」と自ら気づけるかを試す。序盤から全体犯人を明かさない。
